# Tamm - Recruitment Management System

A recruitment management system built with HTML, CSS, JavaScript, and JSON Server.

## Features

* User authentication
* Client dashboard
* Create and manage job requests
* Upload and manage CVs
* Review candidates
* Accept or reject candidates
* Admin dashboard
* JSON Server for data management

## Technologies

* HTML5
* CSS3
* JavaScript (ES6+)
* JSON Server

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Install JSON Server if it is not installed:

```bash
npm install -g json-server
```

4. Start the JSON Server:

```bash
json-server --watch db.json
```

5. Open the project in your browser using Live Server.
